## 🚀 Release v0.2 – GxPAuditTrailReview

**Release Date:** 2026‑03‑05

The concept of scanning audit trails using both deterministic, configurable rules and an AI‑supported engine has proven successful. Audit trail scans can now be performed per system, and each scan can be saved for future reference. Additionally, security features for login, write access, and user management have been implemented.

---

### ✨ New Features

- Ability to add and manage GxP systems
- Ability to run an audit trail scan per system
- Ability to enable or disable deterministic audit trail rules
- Ability to scan audit trails using an LLM based on a defined prompt and audit trail data
- Ability to log in to the system, manage users, and manage user roles
